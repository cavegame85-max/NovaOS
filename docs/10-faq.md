# Шаг 10: Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое NovaOS?

NovaOS — это лёгкий дистрибутив Linux на базе Debian 12, собранный вручную для старого железа. Проект создан для компьютеров, которые не тянут Windows 10 или 11.

### Чем NovaOS отличается от Linux Mint?

- **NovaOS** — минимальная система, собранная с нуля через `debootstrap`. Легче, быстрее.
- **Mint** — готовый дистрибутив с предустановленными программами. Удобнее для новичков.
- **NovaOS** использует **XFCE + Plank**, Mint — Cinnamon.
- **NovaOS** имеет **Wine** из коробки для .exe-программ.

### Это законно?

Да. NovaOS основана на **Debian GNU/Linux** — свободном дистрибутиве. Все компоненты (ядро Linux, X.org, XFCE, Wine) — открытое ПО под лицензиями GPL, MIT и другими.

### Сколько времени занимает сборка?

- **Быстро:** 2–3 часа (по документации).
- **С первого раза:** 5–8 часов (с ошибками и переделками).
- **Полное освоение:** недели практики.

### Можно ли установить на современный компьютер?

Да. NovaOS работает на любом x86_64 CPU. Но смысл её использования — именно на **старом железе**, где Windows не работает.

## Технические вопросы

### Какое ядро используется?

Linux **6.1.0-53-amd64** (LTS). Поддерживается до 2027 года. Есть также 6.1.0-50-amd64 — резервное.

### Почему не самое новое ядро?

Для старых процессоров (Core 2 Duo) **LTS-ядра стабильнее**. Новые ядра (6.6+, 6.14) требуют патчей для драйвера NVIDIA 340. Мы используем **6.1 LTS**, где nouveau и проприетарные драйверы работают из коробки.

### Как добавить программы?

Через `apt`:

    sudo apt install имя_пакета

Найти пакет:

    apt search ключевое_слово

Обновить всё:

    sudo apt update
    sudo apt upgrade -y

### Как установить программы, которых нет в apt?

Несколько способов:
- **Flatpak:** `flatpak install flathub org.example.App`
- **AppImage:** скачать, `chmod +x`, запустить.
- **.deb с сайта:** `sudo dpkg -i file.deb && sudo apt install -f`
- **Snap:** если установлен `snapd`.
- **Собрать из исходников:** `./configure && make && sudo make install`.

### Почему не работает Steam?

Для Steam нужны:
- **Proton** (встроен в Steam).
- **DXVK** (для DirectX 9–11 игр).
- **Vulkan-драйвер.**

Установка:

    sudo apt install steam-installer
    Или через flatpak:
    flatpak install flathub com.valvesoftware.Steam

**San Andreas** (DirectX 9) работает через Proton. **GTA V** — нет (античит).

### Как запустить .exe?

- **Двойной клик** в Thunar — если `binfmt_misc` настроен.
- **Из терминала:** `wine program.exe`.
- **Через Wine-префикс:** `WINEPREFIX=~/.wine wine program.exe`.

### Почему .exe не работает?

Возможные причины:
1. **Wine-префикс не создан** → `WINEARCH=win32 WINEPREFIX=~/.wine wineboot -i`
2. **Windows-версия в префиксе старая** → `winetricks -q win10`
3. **Не хватает библиотек** → `winetricks -q vcrun2019 corefonts`
4. **Программа использует DirectX 12** → не поддерживается Wine 8.0.
5. **Программа использует античит** → невозможно.

### Как обновлять ядро?

    sudo apt update
    sudo apt upgrade -y

Если выйдет новое ядро — оно установится автоматически. Старое останется как резервное.

### Как собирать своё ядро?

Для Core 2 Duo T9300:

    sudo apt install -y build-essential libncurses-dev bison flex libssl-dev libelf-dev
    cd /usr/src
    sudo wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.1.tar.xz
    sudo tar -xf linux-6.1.tar.xz
    cd linux-6.1
    sudo make menuconfig
    В Processor type and features → Processor family → Core 2/newer Xeon
    Затем: make -j2 && sudo make modules_install && sudo make install
    sudo update-grub

**Время:** 4–6 часов на Core 2 Duo.

## Проблемы с графикой

### Чёрный экран после загрузки

**Ctrl+Alt+F1** — переключиться в консоль. Войти. Проверить:

    systemctl status lightdm
    cat /var/log/Xorg.0.log | tail -40

Смотреть строки с `(EE)` — ошибки.

### Низкое разрешение экрана

    xrandr

Показывает поддерживаемые режимы. Установить:

    xrandr --output LVDS-1 --mode 1366x768

### Нет 3D-ускорения

Проверить:

    glxinfo | grep "OpenGL renderer"

Если **llvmpipe** или **software** — 3D нет, используется CPU. Для NVIDIA нужно установить проприетарный драйвер `nvidia-340` (требует патч для ядра 6.1).

## Вопросы о железе

### Какое железо проверено?

- Samsung R528.
- Intel Core 2 Duo T9300 (2.5 ГГц, 2 ядра).
- 6 ГБ DDR2-800.
- NVIDIA GeForce 310M (GT218).
- Atheros AR9285 Wi-Fi.
- Marvell 88E8040 Ethernet.
- Intel ICH9 HD Audio + Realtek ALC269.
- Seagate ST500LM030 500 ГБ HDD.

### Работает ли на других видеокартах?

- **Intel** (i915): да, встроенный драйвер.
- **AMD/ATI** (radeon/amdgpu): да.
- **NVIDIA старые** (GeForce 8xxx–4xx): nouveau или nvidia-340.
- **NVIDIA новые** (GTX 900+): nouveau или nvidia-driver (свежий).

### Что делать с мёртвой батареей?

Если аккумулятор изношен:
- **Не критично** для работы от сети.
- Можно **заменить** на б/у (для Samsung R528 — ~1000–1500 ₽).
- **Или** использовать ноут как **настольный** (всегда от сети).

## Философские вопросы

### Зачем это всё, если есть готовые дистрибутивы?

**Потому что процесс важнее результата.**

- Ты **понимаешь** каждый компонент системы.
- Ты можешь **модифицировать** всё под себя.
- Ты **учишься** Linux на глубоком уровне.
- Ты **создаёшь** что-то своё, а не потребляешь чужое.

Это **не для всех**. Но если интересно — **это один из лучших способов изучить операционные системы**.

### Стоит ли начинать?

**Да, если:**
- Интересно, как работает ОС изнутри.
- Есть **старый ноут**, который не жалко.
- Есть **2–3 часа** в день в течение недели.
- Терпимость к **ошибкам и переделкам**.

**Нет, если:**
- Нужен **быстро работающий компьютер** — бери Linux Mint.
- Нет времени **разбираться**.
- Ждёшь **готовый продукт** — тут его нет.
