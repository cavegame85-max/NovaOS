# NovaOS — Обзор проекта

## Что такое NovaOS

NovaOS — это **лёгкий дистрибутив Linux**, собранный вручную на базе **Debian 12 (bookworm)**. Проект создан для старого железа (Intel Core 2 Duo, NVIDIA GeForce 310M, 6 ГБ DDR2), которое не тянет современные Windows.

NovaOS — это **не готовый дистрибутив**, а **набор инструкций и конфигов**, позволяющих собрать систему с нуля. Код и конфиги лежат в этом репозитории.

## Философия проекта

1. **Лёгкость.** Минимум пакетов, только необходимое.
2. **Понимание.** Каждый компонент установлен осознанно.
3. **Совместимость.** Wine для .exe-программ из Windows.
4. **Уникальность.** Свой логотип, свой стиль, свой подход.

## Что уже сделано

- ✅ База Debian 12 (debootstrap, minbase)
- ✅ Ядро Linux 6.1.0-53-amd64 (LTS)
- ✅ systemd как инициализация
- ✅ Wi-Fi (Atheros AR9285), Ethernet (Marvell 88E8040)
- ✅ NVIDIA GeForce 310M (nouveau)
- ✅ Звук (Intel HDA + Realtek ALC269)
- ✅ Графика: X.org + XFCE 4.18
- ✅ Экран входа: LightDM + GTK Greeter
- ✅ Док: Plank (с часами и датой)
- ✅ Тема: Arc-Dark
- ✅ Иконки: Papirus-Dark
- ✅ Шрифты: Inter + JetBrains Mono
- ✅ Wine 8.0 + binfmt_misc (двойной клик по .exe)
- ✅ fastfetch с логотипом NovaOS
- ✅ Скрипт резервного копирования (novaos-backup)

## Минимальные требования

| Компонент | Минимум | Рекомендуется |
|---|---|---|
| CPU | 2 ядра x86_64 | Core 2 Duo и выше |
| RAM | 2 ГБ | 4 ГБ и выше |
| Диск | 10 ГБ | 30 ГБ и выше |
| GPU | любая с nouveau/radeon/intel | NVIDIA GeForce 310M (проверено) |
| Wi-Fi | любая с поддержкой в ядре | Atheros AR9285 (проверено) |
